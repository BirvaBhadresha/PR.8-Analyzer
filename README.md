📌 Project Overview

NumPy Analyzer is a menu-driven Python project developed using the NumPy library. It allows users to create and manipulate multidimensional arrays and perform various mathematical and statistical operations.

This project uses Object-Oriented Programming (OOP) concepts, including classes, objects, constructors, encapsulation, class methods, and static methods.

🎯 Objectives

- To understand and implement NumPy arrays.
- To perform mathematical operations on arrays.
- To understand indexing and slicing.
- To combine and split arrays.
- To search, sort, and filter array elements.
- To calculate statistical values using NumPy.
- To implement OOP concepts in Python.

⚙️ Installation and Setup

Step 1: Install Python

Download and install Python if it is not already installed on your computer.

Step 2: Install NumPy

Open the terminal in Visual Studio Code and run:

py -m pip install numpy

Step 3: Create the Project File

Create a Python file named:

numpy_analyzer.py

Copy the project code into this file and save it.

Step 4: Run the Program

Open the terminal in the project folder and execute:

py numpy_analyzer.py

The NumPy Analyzer main menu will appear in the terminal.

▶️ How to Use

1. Run the Python program.
2. Select an operation from the main menu.
3. Create an array before performing operations that require one.
4. Enter the requested values.
5. View the results in the terminal.
6. Select the Exit option to close the program.
